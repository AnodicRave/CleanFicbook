# Clean Ficbook

Расширение Chrome для скрытия баннеров промо и премиума на ficbook.net

## Что скрывает
- Промо-карусели
- Плашки "Скидки"
- Кнопку "Улучшить аккаунт"

## Установка
1. Скачай или клонируй репозиторий
2. Открой `chrome://extensions/`
3. Включи "Режим разработчика"
4. "Загрузить распакованное расширение" -> выбери папку
