# Clean Ficbook

Расширение для скрытия баннеров промо и премиума на ficbook.net

## Что скрывает
- Рекламу промо
- Плашки "Скидки"
- Кнопку "Улучшить аккаунт"

## Установка

### На ПК
1. Скачайте или клонируйте репозиторий
2. Откройте в браузере вкладку расширений
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с расширением

### На Android
1. Установите браузер с поддержкой расширений (Kiwi, Quetta, Firefox)
2. Скачайте ZIP-архив (Code -> Download ZIP)
3. Откройте в браузере вкладку расширений
4. Включите "Режим разработчика"
5. Нажмите "Загрузить", выберите файл с расширением
